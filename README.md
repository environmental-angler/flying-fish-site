# Flying Fish Stream Science — website

Draft one-page website for Flying Fish Stream Science, a fisheries consulting practice in East Machias, Maine (aquatic connectivity: road-stream crossing assessment, construction documentation, effectiveness monitoring, and NDAA-compliant drone surveys).

Built on the StoryBrand (SB7) framework: the client is the hero, the firm is the guide, and the plan is Assess → Document → Verify.

## Structure
- `index.html` — the whole site: HTML, CSS, and a few lines of JavaScript in one file. Fonts load from Google Fonts.

## Hosting
Served with GitHub Pages from the `main` branch (Settings → Pages → Deploy from a branch → `main` / root).
